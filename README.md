# Minimalist Flask To-Do App

A clean, modern, and lightweight To-Do list application built with Python (Flask) and vanilla HTML/CSS/JS.

## Running the App

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python main.py
   ```

3. Open your browser and navigate to `http://127.0.0.1:5000`.

## Running Tests

```bash
pytest
```
